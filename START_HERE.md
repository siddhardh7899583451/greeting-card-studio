# START HERE – Greeting Card Studio

## Quick Start (Windows)

1. Open the folder: `greeting-card-studio\frontend`
2. Double-click **index.html**
3. The app opens in your browser.

That’s it. No installation, no Node, no Python required for basic use.

## First Card in 60 seconds

1. Click **Create Your Card**
2. Pick an occasion from the Setup tab (e.g. Birthday)
3. Click a template under “Template”
4. Edit the text on the card (double-click or select + edit)
5. Add stickers from the Elements tab
6. Click **Download** → PNG

## Offline note

- Creating, editing and saving cards works fully offline.
- Export (PNG/JPEG/PDF) uses libraries loaded from a CDN the first time. After the first successful export, cached copies allow offline export in many browsers.

## Troubleshooting

- **Blank page**: Make sure you opened `index.html` from the `frontend` folder (data.js, app.js, styles.css must be next to it).
- **Export fails**: Check internet for the first export, or open the browser console (F12) for errors.
- **Saved designs missing**: Designs are stored in the browser’s localStorage for that origin. Using a different browser or clearing site data removes them.

Enjoy creating beautiful cards!
